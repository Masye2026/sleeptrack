EXPECTED NOTIFICATION EXAMPLE{"heartRate": 62, "spo2": 97, "timestamp": "2026-10-16T20:15:00Z"}Only fields actually present in a received packet will be shown. Missing values remain blank.

BROWSER COMPATIBILITY

Where Bluetooth works

Web Bluetooth is generally supported by Chromium-based browsers on compatible desktop and Android devices, in a secure context (HTTPS or localhost). It is not supported by Safari on iPhone/iPad. For iOS support, the project will likely need a native companion app or a different hardware integration path.
